    How a response is approved

    1. The Actor drafts a response from the request and the retrieved context.
    2. The Guardian checks the draft against four maxims and returns a JSON verdict.
    3. On FAIL, the Actor revises using the Guardian's directives, up to the revision limit.
    4. A draft is approved only on an explicit PASS. An unreadable verdict is never a PASS.
